# STELLARIS — Telegram Casino Mini App

Мини-приложение для Telegram-бота: баланс в **Stars** и **TON**, пополнение и пять игр.

## Игры

- **Мины** — поле 5×5, открывай клетки, забирай множитель или взорвись
- **Орёл и решка** — ставка + выбор стороны, множитель ×1.95
- **Шансер** — круг с зелёной зоной; меньше зона — выше выплата
- **Коровка** — прыжки через люки, риск растёт с каждым шагом
- **Кружки** — выбери кружку; приз под одной

## Стек

- React + Vite + TypeScript
- Framer Motion
- Telegram WebApp API (`telegram-web-app.js`)

Баланс пока в `localStorage` (демо). Исходы клиентские — перед продом заменить на сервер бота.

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```

## Подключение к боту

1. Задеплойте `dist/` на HTTPS.
2. В BotFather: `/newapp` → URL мини-аппа.
3. Позже: инвойсы Stars (XTR) и TON Connect / платежи бота вместо демо-пополнения.
